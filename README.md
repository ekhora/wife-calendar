# ปฏิทินฤกษ์คุณภรรยา

ปฏิทินวันดีวันร้ายและยามดีร้าย พ.ศ. 2522–2575 สำหรับดวง 丙寅 己亥 丙子 戊戌

- 宜忌รายวันจาก月表《欽定協紀辨方書》 (ถอดจากภาพฉบับ文淵閣四庫全書)
- กรองตามชุดกิจกรรม: ราชสำนัก (御用六十七事) · ชาวบ้าน (民用三十七事) · 通書選擇六十事
- วันพระตามปฏิทินจันทรคติไทย
- ยามดีร้ายเป็นเวลานาฬิกากรุงเทพฯ

หน้าเว็บนี้สร้างจากสคริปต์ในโปรเจกต์แปลตำรา ไม่ต้องแก้ไฟล์นี้ด้วยมือ
